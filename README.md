# 资产管理中枢

## 快速开始

- **网页版**：按 [打包说明.md](打包说明.md) 第一步生成浏览器版，用浏览器打开；数据保存在本机 `localStorage`
- **Android**：构建 APK 后安装，首次为空态
- **Linux**：构建出 AppImage 后 `chmod +x` 再运行

## 数据契约

本版为全新契约，不兼容原「账本」项目的本地数据与云端备份，请勿跨项目混用。

- `localStorage` 键：`amhub_v100_db` / `amhub_v100_theme` / `amhub_v100_config` / `amhub_v100_nutstore` / `amhub_v100_autobackup` / `amhub_v100_added`
- 坚果云目录：`资产管理中枢`，旧目录 `资产管理中枢备份` 作回退；主文件 `backup.json`
- 备份文件名：`资产管理中枢_备份_YYYYMMDD_HHMMSS.json`
- 导出标记：`__app='资产管理中枢'`，`__ver='v1.0.0'`
- 包名 `com.amhub.app`，versionCode 1，原项目为 38，Android 侧属独立新应用，不能覆盖安装或继承原项目数据

## 构建与自检

完整步骤、密钥与口令管理、故障排查见 [打包说明.md](打包说明.md)。速览：

```bash
python3 源码/打包脚本/build_amhub.py                    # ① 页面
ANDROID_TOOLS=/path/to/android-tools \
  python3 源码/打包脚本/build_apk.py                    # ② APK
PY=/path/to/python3 bash 源码/linux/build_linux.sh      # ③ AppImage
node 算法自检.js                                        # 口径自检
```

产物默认输出到 `发布版/`，浏览器版页面落在 `源码/`。

## 安全说明

- **签名密钥不随公开仓库分发**：`*.jks` 已在 `.gitignore` 中排除，仅保存在构建机本地
- **换签名即换血统**：用不同密钥签出的包与已装机旧包签名不同，系统会拒绝覆盖安装，只能卸载重装，本地数据请先导出备份
- 页面内填写的坚果云邮箱与许可密码、记账数据全部保存在浏览器本机，不会随仓库分发
- 构建脚本不硬编码任何账号或口令：签名口令由环境变量 `AMHUB_KS_PASS` 或 `密钥/keystore.pass` 提供，凭据自检清单放 `密钥/leak_guard.txt`，两者均被 `.gitignore` 排除
