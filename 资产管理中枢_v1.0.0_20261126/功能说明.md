## 三、边框与卡片体系（本版细调核心）

### 3.1 边框粗细：2px → 1px

```css
--bd:1px;                              /* 全站边框粗细：对齐同类看板应用 */
--line:var(--bd) solid var(--edge);    /* 引用方式不变，边框色仍走 --edge */
```

`--bd` 全站共 10 处（1 处定义 + 9 处引用）全部走新值；无 `--bd:2px` / `--bd:3px` 残留。
边框色仍由 v1.4.5 引入的 `--edge` 承载（亮 `#c9d6e8` / 暗 `#2d3a52`），文字色 `--ink` 与之解耦不变。

### 3.2 dock 四按钮：折叠 → 独立

改前用负左边距把四块边框折叠成一条线（内部接缝重叠 2px）；改后拆独立卡片：

```css
.bottombar{display:flex;justify-content:center;gap:6px;}
.bottombar>button{margin-left:0;}
.bottombar>button,
.bottombar>button:first-child,
.bottombar>button:last-child{border-radius:var(--r);}   /* 四块全圆 */
```

四块等宽等高不变（实测 98×36，间距 6px），只把「共边」改为「各自四边 + 间隙」。

### 3.3 账单页流水条：分隔线 → 独立卡片

```css
body:not(.tab-asset):not(.tab-overview) .flow-list{gap:6px;padding-top:8px;}
body:not(.tab-asset):not(.tab-overview) .flow-row{
  border:var(--line);
  border-radius:var(--r-s);
  padding:var(--flow-gap) 6px;
}
```

基础 `.flow-row` 仍只有下边框、直角；圆角与四边框只由账单页覆盖层提供，
避免总览 / 资产页误伤。实测账单页 11 条流水四边 1px / 圆角 4px / 间距 6px。

## 四、去外框与日期框圆角

账单页 `.panel` 去掉整页大外框（`border:0;border-radius:0`），宽度不变（实测 418px）。
日期区拆两段保留圆角过渡：

```css
body:not(.tab-asset):not(.tab-overview) .cal{border:var(--line);border-radius:var(--r) var(--r) 0 0;}
body:not(.tab-asset):not(.tab-overview) .datebar{border:var(--line);border-top:0;border-radius:0 0 var(--r) var(--r);}
```

总览 / 资产页去外框维持 v1.4.5 结论（本版规则用 `body:not(...)` 精确限定账单页）。
实测：panel 边框 1px→0、圆角 8px→0；`.cal` 上两角 8px、`.datebar` 下两角 8px；
日期栏→首条流水 0→8px；总览 / 资产页零误伤。

## 五、资产页合计文本与末尾横线

两条「合计」文本行只在显示层隐藏，不改渲染函数与数据：

```css
body.tab-asset .asset-row.subtotal{display:none;}
```

实测可见合计行 2→0、可见账户行 15→13，顶部三张汇总卡数值不变。

移除合计行后暴露的末尾横线，定位为两张账户卡最后一条明细行下的 `border-bottom`：

```css
body.tab-asset .asset-group > .asset-item:nth-last-child(2) .asset-row,
body.tab-asset .asset-group > .asset-item:nth-last-child(2) .credit-meta,
body.tab-asset .asset-group > .asset-item:last-child .asset-row,
body.tab-asset .asset-group > .asset-item:last-child .credit-meta{border-bottom:0;}
```

实测资产卡（建设银行）与信贷卡（宁波银行信用卡）末尾横线 1px→0；
中间行 / 表头 / 卡片外框仍 1px，汇总卡数值不变。

## 十、如实说明

1. **「合计」是隐藏不是删除。** 资产页两条「合计」文本用 CSS `display:none` 隐藏，
   数据字段与汇总卡数值都还在；历史备份文件不受影响。
2. **归档里的成品页不要用 IDE 预览面板直接打开。** 预览器会把 `data-page-node-id="…"`
   逐元素回写进文件，打掉「内嵌页与源码逐字节一致」及所有依赖字节比的断言。
   要看效果请复制一份到工作区再预览，副本是可再生草稿，不拿它做哈希基线。
3. **AppImage 在构建机（容器）里要 `APPIMAGE_EXTRACT_AND_RUN=1` 才能跑。**
   这里 FUSE 不可用，直接执行会报 `fusermount: mount failed`，属环境限制，正常桌面双击即可。
4. **账单页最外层大框被有意去掉**，但日期框圆角与内部流水卡片边框都保留；这是需求，不是样式丢失。
5. **dock 四按钮现在是四个独立小卡片**，彼此留 6px 间隙、各自四角全圆；不再是共用边框的一整条。
6. **APK 内有两处底座壳既有的英文标识无法去掉**：`resources.arsc` 的资源主题名 `Theme.PnlBoard`、
   `classes.dex` 的入口类 `PnlBoardApp`。它们属于所复用的通用 WebView 壳（模式 B 只替换
   `assets/index.html` 与清单字段，dex 与 arsc 逐字节沿用），不重编译原生工程就无法改名，
   也**不代表**本项目命名或数据契约；签名证书 DN `CN=账本` / `OU=Ledger` 同理，属签名身份而非产品名。
7. **AppImage 用同一份源码重建不保证逐字节相同**。多次构建实测：内嵌可执行文件体积在
   10,005,616 / 10,006,552 B 之间浮动，squashfs 段大面积不同，总长在 10,848,760 / 10,852,856 B 之间浮动，
   但 AppImage runtime 段（前 944,632 B）与内嵌页逐字节一致。
   判断「是否为同一版本」请看**内嵌页哈希**（`b3d68148…`）与 `--version` 输出，不要用 AppImage 整体哈希；
   归档里出现过的 `ca1e17ff…` / `a564e79a…` 都只是某次构建实物的哈希，不是可复现的构建指纹。
